How Hash Chaining Works

Each event stores the SHA-256 hash of its canonical JSON payload and the content hash of the previous event. The first event has previous_hash = null. If any event in the chain is modified, the computed hash will not match the stored content_hash, and all subsequent events will fail their previous_hash check — providing tamper evidence.
